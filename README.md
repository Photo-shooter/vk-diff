# vk-diff

Сравнение локальной папки с фотоальбомом ВКонтакте: поиск недостающих и дублирующихся фото по перцептивному хэшу (pHash).

## Возможности
- Сравнение локальных фото с альбомом ВК (API + HTML-парсинг).
- Поиск недостающих и дубликатов.
- Миниатюры и простой GUI на Tkinter.
- Кэширование хэшей, отчёты в CSV, логирование.

## Установка
Требуется Python 3.8+.

На Linux доустанавливаем Tkinter, если его нет:

sudo apt install python3-tk

Установим виртуальное окружение на всякий случай и в нем зависимости

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt

Запускаем

python vk_diff.py
